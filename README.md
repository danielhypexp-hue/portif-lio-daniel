# Portfólio - Daniel Oliveira

Site portfólio pessoal desenvolvido para o projeto final.

## Tecnologias
- HTML5
- CSS3
- JavaScript

## Estrutura
- `index.html` - estrutura do site
- `css/style.css` - estilos e responsividade
- `js/script.js` - interações
- `imagens/` - imagens do projeto

## Publicação no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie todos os arquivos mantendo as pastas.
3. Acesse `Settings > Pages`.
4. Em Source, selecione `Deploy from a branch`.
5. Escolha a branch `main` e a pasta `/ (root)`.
6. Clique em `Save`.
7. Aguarde a publicação e abra o endereço informado pelo GitHub.

## Personalização
Antes de publicar, troque os links do GitHub e LinkedIn e o e-mail em `index.html`.
Você também pode adicionar imagens próprias na pasta `imagens/`.
